# 斑马鱼毒理图谱 · Zebrafish Toxicology Atlas

- 在线地址：https://kkhins.github.io/my-page/zebrafish/
- 一个纯静态、可离线双击打开的斑马鱼生态毒理知识图谱。三栏布局：左导航、中 SVG 解剖图 + 生命周期时间轴、右详情与文献列表。参考线虫站（`../web-export/`）的视觉语言，但按任务书改为纯 SVG，不依赖 three.js、不依赖任何 CDN。

## 打开方式

**直接双击 `index.html`**（`file://` 即可，不需要起服务器）。页面不发起任何网络请求，断网可用。

## 交付文件（5 个，全部在根目录）

| 文件 | 作用 |
| --- | --- |
| `index.html` | 页面骨架 + 全部 CSS（无内联脚本、无外部字体/图片） |
| `data_struct.js` | 任务书第 3 节结构数据，`window.STRUCT = {organs, directions, marks, stages, pages}` |
| `data_papers.js` | 430 篇文献，`window.PAPERS = [...]` |
| `anatomy.js` | 三视图 SVG 解剖图，`window.Anatomy` |
| `app.js` | 导航 / 筛选 / 排序 / 搜索 / 渲染 / localStorage |

另有 `anatomy-preview.html`（解剖图独立自测页）与 `_selftest/`（解剖图的渲染证据），不属于交付文件。

## 数据

- **430 篇**，全部来自 NCBI E-utilities 的实际返回（esearch → efetch XML），无一条凭记忆书写。抓取脚本 `tools/fetch_pubmed.py`，36 条检索式，候选池 695 篇（`work/pool.json` / `work/candidates.json`）；逐篇读摘要打标后 score≥2 的合格池 595 篇，按方向配额选入 430 篇。
- 八方向按**主方向（`dirs[0]`）**分配配额：发育毒性 70、神经行为 65、心血管毒性 42、内分泌干扰 52、生殖与跨代 52、氧化应激与解毒 65、衰老 34、方法与标准 50，合计 430。（2026-11-09 按你的要求从任务书的 200–280 扩到 430，因此超出原配额表。）
- 每篇至少 1 个方向、最多 3 个；器官最多 3 个、标志物最多 5 个、阶段最多 4 个。导航里的方向/器官计数是"含该标签的篇数"，因此会大于上面的主方向配额（多标签叠加），这是预期行为。
- `key: true` 16 篇；综述 24 篇；`zh` 空 0 篇（全部依摘要写成 20–60 字发现陈述）。
- 430 篇中有 **146 篇没有 `organs` 字段**（多为行为、方法学与综述），因此只出现在方向页、最新发表与书单里，不出现在器官页——这是数据事实，不是渲染缺失。
- 污染物大类分布：农药 105、新兴污染物 87、无明确污染物 63、EDC 49、金属 35、有机磷 30、塑料 28、混合 13、纳米 11、PAH 9。
- 年份：2023 年 90、2024 年 75、2025 年 74、2026 年 33，2021–2022 共 97 篇，其余为更早的经典文献（最早 2003）。
- DOI：429 个逐条请求 `https://doi.org/<doi>`，**429/429 返回 2xx/3xx**；唯一无 DOI 的是 PMID 15953964（PubMed 记录本身没有 DOI），保留该篇但不写 `doi` 字段。

## 页面功能

- 8 个一级导航：斑马鱼简介、饲养与暴露、器官解剖（11）、研究方向（8）、生物标志物（48，按 `cat` 分组）、生命周期（12）、最新发表（year 降序前 30）、我的书单。左栏为手风琴：8 个顶层项常驻，点组头展开子项并进入该组首条。
- 中栏三视图：侧视（成鱼，默认）、躯干横截面、胚胎（约 48 hpf）；hover 高亮 + 标签，click 联动右栏与左导航；标签开关、其他器官半透明开关；12 阶段时间轴联动胚胎视图。
- 右栏文献列表：关键词（标题 + `zh` + 污染物名）、污染物大类、研究方向、生命阶段、代际深度、综述/待读/已读筛选；排序（相关度/年份/期刊）；卡片可标已读、写笔记。
- `⌘K` / `Ctrl+K` 聚焦全局搜索，匹配基因、器官、标志物、污染物、标题，结果分组并高亮。
- 状态存 `localStorage`：`zfatlas-read-status`、`zfatlas-notes`，不上传。
- 所有计数（顶部 430 篇、各导航角标、筛选条数、统计卡）均在运行时由 `PAPERS` 计算，无硬编码数字。

## 工具与中间产物

- `tools/fetch_pubmed.py`：检索 + 抓取 + 解析（标准库，E-utilities）。
- `tools/build_struct.py`：从任务书提取结构数据（含逐字校验与引号转义）。
- `tools/merge_annot.py`：合并 9 批标注并按主方向配额选 430 篇。
- `tools/verify_doi.py`：并发验证 DOI，失败重试。
- `tools/check_delivery.py`：交付前校验（数量、PMID 来源、语法、禁用字符串、DOM 假设）。
- `work/`：候选池、标注输入输出、DOI 结果等中间数据，可整体删除，不影响页面。
